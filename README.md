# DataQuant website

A South African data consultancy: we help organisations use their data, automate their work and keep that data safe.

Plain static site: no build step. Open `index.html` in a browser, or serve the folder with any static host (Cloudflare Pages, GitHub Pages).

## Pages
- `index.html` Home
- `services.html` Data Strategy & Analytics, Data Engineering, Data Security & Governance
- `about.html` About
- `contact.html` Contact form (not yet connected to a sending endpoint)
- `privacy.html` POPIA privacy notice
